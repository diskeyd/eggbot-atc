# 공유받은 `변환 프로그램.exe` 비교

팀에서 공유받은 윈도우용 `변환 프로그램.exe`가 무엇인지, 우리 `eggbot-atc`와 무엇이 다른지 쉽게 정리했습니다.
결론만 먼저: **그림 미리보기·공부용으로는 괜찮지만, 이 프로그램이 만든 G-code를 우리 기계에 보내면 안 됩니다.**

## 1. 이 프로그램은 뭐예요?

- 이름: **EggBot Rotary ATC Master Simulator PRO**
- 파이썬으로 만든 창 프로그램을 exe 하나로 묶은 것입니다 (PyInstaller, Python 3.13, tkinter).
- 하는 일:
  1. G-code 파일을 연다.
  2. 색(레이어)이 바뀌는 곳을 찾는다. 못 찾으면 그냥 3등분한다.
  3. 색이 바뀌는 곳마다 "펜 바꾸기" 코드 9줄을 끼워 넣는다.
  4. 화면에 그림을 그려 보여 주고(미리보기·재생), 저장한다.
  5. G코드·M코드 설명표도 보여 준다.

### 안전한가요?

exe를 **실행하지 않고** 속을 열어 코드를 읽어 봤습니다 (2026-09-28).

- 쓰는 모듈은 `tkinter`(창), `os`, `re`(글자 찾기) 뿐입니다.
- 인터넷 연결, 다른 프로그램 실행, 비밀번호·쿠키 훔치기 같은 코드는 **없습니다**.
- 파일은 내가 고른 G-code를 읽고, 내가 고른 곳에 저장하는 것만 합니다.
- 함께 묶인 DLL 파일까지 전부 검사하진 않았습니다. 더 확실히 하려면 아래 지문(SHA-256)을 VirusTotal에서 검색해 보세요.
  `92123bfba46298999afa73f6212b8de76e111192fd62cd14df15423741525b0f`

## 2. 한눈에 비교

| | 공유받은 프로그램 | 우리 eggbot-atc |
|---|---|---|
| 넣는 것 | 이미 만든 G-code | Inkscape SVG (레이어 = 펜) |
| 색 바뀌는 곳 찾기 | 좌표를 보고 짐작, 못 찾으면 3등분 | 레이어 이름 `T1 red` 또는 `T<n>` 줄 |
| Z축 | 매거진 **앞뒤로 밀기** | 매거진 **돌리기** (도) |
| A축 | 매거진 **돌리기** | 슬라이드 **앞뒤로 밀기** (mm) |
| 펜 캐리지(X) | 안 움직임 | park → dock → release로 움직임 |
| 펜 3개 각도 | 0°, 180°, **360°** | 0°, 120°, 240° (`slot0 + (n-1)×360/슬롯수`) |
| 펜 내리기 | `M3 S0` | `M3 S30` |
| 좌표 값 | 코드에 고정 (Z100, Z80, A45…) | `machine.toml`에서 측정값 입력 |
| 펜 바꾼 뒤 | 원래 그리던 자리로 안 돌아감 | 원래 X·Y로 돌아감 |
| 미리보기 화면 | 있음 | 없음 |

## 3. 왜 우리 기계에 쓰면 안 돼요? (쉽게)

### ① 축 이름표가 서로 바뀌어 있어요
리모컨의 "채널 올리기"와 "소리 올리기" 버튼이 바뀐 것과 같아요.
그 프로그램이 "매거진 100만큼 앞으로!"(`Z100`)라고 하면, 우리 기계는 **매거진을 100도 돌려요**.
"매거진 45도 돌려!"(`A45`)라고 하면, 우리 기계는 **슬라이드를 45 mm 밀어요**. 부딪쳐서 부서질 수 있어요.

### ② 3번 펜이 1번 펜 자리에 가요
원을 한 바퀴 돌면(360°) 처음 자리(0°)로 돌아오죠.
그래서 0°, 180°, 360°로 나누면 1번과 3번이 **같은 자리**예요. 펜 3개는 120°씩 떨어져 있어야 해요.

### ③ 펜 내리기 숫자가 너무 세요
`M3 S` 뒤의 숫자는 각도가 아니라 "힘 세기"예요. `S0`을 주면 서보가 끝까지 확 튀어요.
우리는 `S30`처럼 적당한 값을 씁니다.

### ④ 숫자를 재지 않고 정해 놨어요
`Z100`, `Z80` 옆에 프로그램 스스로 "★실제 좌표로 수정 필요"라고 적어 놨어요.
우리는 기계를 직접 재서 `machine.toml`에 넣고, 안 잰 값(TODO)이 있으면 변환을 **거부**해요.

### ⑤ 펜 바꾸는 방법이 달라요
그 프로그램은 매거진을 돌려서 펜을 "낚아채는" 방식이고, X(펜 캐리지)는 가만히 있어요.
우리 기계는 캐리지가 매거진 쪽으로 가서 펜을 꽂고 빼는 방식이에요. 숫자만 고쳐서는 맞출 수 없어요.

### ⑥ 펜을 바꾼 뒤 제자리로 안 돌아가요
그 프로그램은 펜을 바꾸고 나서 원래 그리던 자리로 돌아가지 않아요. 그래서 다음 선이 엉뚱한 곳에서 시작돼요.

## 4. 그럼 어떻게 써요?

- ✅ G-code 공부, 그림 미리보기, 코드표 보기 → 써도 됨 (윈도우에서만 실행됨)
- ❌ 저장한 G-code를 기계로 보내기 → **안 됨**
- 실제로 기계에 보낼 G-code는 README 순서대로 `uv run eggbot-atc`로 만드세요.
- 미리보기 기능이 좋으면, 파이썬 소스(`.py`)를 받아 우리 축 배정에 맞게 고치는 걸 같이 얘기해 봐요.
