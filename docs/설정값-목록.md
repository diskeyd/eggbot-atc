# 설정값 목록 (`machine.toml`)

기계를 돌리기 전에 채우거나 확인해야 하는 값을 전부 모았습니다.
영점 잡는 법과 ATC 동작 순서는 [README](../README.md)를 보세요.

값은 모두 **영점(`G92 X0 Y0 Z0 A0`) 기준 절대 좌표**입니다. 영점 자세: X(펜 암) 왼쪽 끝 각도, A 완전 후퇴, 매거진 슬롯 1이 팔과 마주 봄.

## 1. 꼭 재야 하는 값 — 없으면 `convert`가 거부함 (8개)

`uv run eggbot-atc check`에 나오는 값들입니다. 0으로 잘못 두면 슬라이드·매거진이 부딪히기 때문에 `"TODO"`인 동안은 변환 자체를 막습니다.

| 키 | 단위 | 무엇 | 어떻게 재나 |
|---|---|---|---|
| `machine.x_max_deg` | 도 | 펜 암 최대 회전각 → GRBL `$130` | 왼쪽 끝 영점에서 오른쪽 끝까지 조그 |
| `drawing.svg_width_deg` | 도 | SVG 가로 전체가 대응될 펜 암 회전각 | 계란 위에서 펜이 그릴 수 있는 좌우 범위 |
| `drawing.x_offset_deg` | 도 | SVG 왼쪽 끝이 놓일 X | 펜이 계란 그림 영역 왼쪽 끝에 오는 X. `x_offset_deg + svg_width_deg`가 `x_max_deg`를 넘으면 변환 거부 |
| `atc.park_x` | 도 | 펜 암이 매거진 갈퀴와 만나는 X | 슬라이드를 밀었을 때 펜 고정부가 갈퀴 안에 들어오는 X |
| `atc.release_x` | 도 | 펜을 갈퀴에 두고 팔만 빠진 X | `park_x`에서 X를 돌려 자석이 완전히 떨어지는 곳 |
| `atc.slide_in_mm` | mm (A축) | 매거진이 팔에 밀착된 위치 | A를 조그로 밀어 밀착 |
| `atc.slide_out_mm` | mm (A축) | 완전 후퇴 (그리는 동안) | 보통 `0` |
| `atc.slot0_deg` | 도 (Z축) | 슬롯 1의 매거진 각도 | 영점을 슬롯 1에 맞췄으면 `0`. 슬롯 n = `slot0_deg + (n−1)·360/slot_count` |

## 2. 기본값이 들어 있지만 기계에서 확인할 값

지금 적힌 숫자는 부품 사양으로 넣은 **추정치**입니다. 틀리면 그림 크기·위치가 어긋납니다.

| 키 | 현재값 | 확인할 것 |
|---|---|---|
| `machine.motor_steps` | `200` | NEMA 17 1.8°/스텝이면 그대로 |
| `machine.microsteps` | `32` | DRV8825 점퍼 3개(M0·M1·M2)를 모두 꽂았는지 (1/32) |
| `machine.x_gear_ratio` | `1` | 펜 암이 모터 축에 직결이면 1 (도면: 펜 암 하단 Ø5.2 + M4 고정나사) |
| `machine.a_lead_mm` | `8` | 슬라이드 T8 리드스크루가 4줄(리드 8 mm)인지 1줄(리드 2 mm)인지. `G91 G1 A10` 후 자로 재기. 틀리면 슬라이드가 4배 더 가서 부딪힘 |
| `machine.y_gear_ratio` | `1` | 계란 축이 모터 직결이면 1. 기어·벨트가 있으면 (계란 쪽 톱니 ÷ 모터 쪽 톱니) |
| `machine.z_gear_ratio` | `1` | 매거진이 모터 직결이면 1 (도면: 매거진 허브 Ø5.2 + Ø3.3 고정나사) |
| `drawing.pen_up_cmd` | `"M3 S90"` | **튜닝 필수.** 펜이 계란에서 확실히 뜨는 S값 (0~255, 각도 아님) |
| `drawing.pen_down_cmd` | `"M3 S30"` | **튜닝 필수.** 펜이 계란에 닿는 S값 |
| `drawing.pen_dwell_ms` | `300` | 서보가 다 움직이기 전에 축이 출발하면 늘리기 |
| `drawing.y_invert` | `false` | 그림이 위아래 뒤집혀 나오면 `true` |
| `atc.slot_count` | `3` | 매거진 슬롯 수 (도면: 포크 3개, 120° 간격) |
| `atc.twist_deg` | `45` | 갈퀴가 펜에서 완전히 비켜나는 매거진 회전각 (팀원 프로그램 값). 펜을 문 채 Z만 돌려 확인 |
| `atc.initial_tool` | `0` | 시작할 때 팔에 펜이 없으면 0. 중간에 멈춘 뒤 펜을 문 채로 다시 돌릴 땐 그 펜 번호 |

## 3. 속도 (처음엔 낮게)

| 키 | 현재값 | 설명 |
|---|---|---|
| `drawing.draw_feed` | `1500` | 그릴 때 속도. X·Y는 도(°)를 mm처럼 셈 |
| `drawing.travel_feed` | `3000` | 현재 코드에서 쓰이지 않음 (이동은 `G0` = GRBL 최대 속도) |
| `atc.atc_feed` | `600` | ATC 동작 속도. 첫 시운전은 `200` 정도로 |
| `drawing.flatten_mm` | `0.5` | 곡선을 이 간격으로 쪼갬. 작을수록 매끄럽고 파일이 커짐 |

## 4. GRBL 속도·가속·이동 한계 (`[grbl]` 표, 선택)

안 적으면 `settings` 출력에 `; $11x=TODO` 주석으로 남고 펌웨어 기본값이 쓰입니다. 모터가 탈조(소리 나며 스텝 놓침)하면 여기서 낮춥니다.

| 키 | GRBL | 설명 |
|---|---|---|
| `x_max_rate` `y_max_rate` `z_max_rate` `a_max_rate` | `$110`~`$113` | 축별 최대 속도 (X·Y·Z는 °/min, A는 mm/min) |
| `x_accel` `y_accel` `z_accel` `a_accel` | `$120`~`$123` | 축별 가속도 |
| `x_max_travel` | `$130` | 안 적으면 `machine.x_max_deg` 사용 |
| `y_max_travel` | `$131` | 360 이상 |
| `z_max_travel` | `$132` | `slot0_deg + 240 + twist_deg` 이상 |
| `a_max_travel` | `$133` | 슬라이드 최대 이동 |

## 5. 값 말고 미리 끝내야 하는 것

설정값을 다 채워도 아래가 안 돼 있으면 돌아가지 않습니다.

- **펌웨어**: grbl-Mega-5X를 Mega 2560에 올리고, `config.h`에서 스핀들 PWM 핀을 **D6**(`SPINDLE_PWM_ON_D6`)으로 옮기고 빌드. 기본 D8과 D9는 RAMPS에서 12 V MOSFET 출력이라 서보가 타버립니다.
- **서보 동작 확인**: UGS 콘솔에서 `M3 S30`, `M3 S90`을 보내 펜이 실제로 오르내리는지. 안 움직이면 서보 포크(`M96`)로 바꿔야 함 (README "서보 주의" 참고).
- **GRBL 설정 적용**: `uv run eggbot-atc settings` 출력을 UGS 콘솔에 붙여넣기.
- **축 방향**: 각 축을 `+10` 조그해서 기대한 방향으로 도는지. 반대면 GRBL `$3`(방향 반전 마스크)로 뒤집기.
- **도안**: Inkscape에서 색마다 레이어(`T1 빨강` …), 선(stroke)만, 캔버스 세로 = 계란 한 바퀴.

## 채운 뒤 순서

```bash
uv run eggbot-atc check                          # all measured 확인
uv run eggbot-atc settings                       # UGS 콘솔에 붙여넣기
uv run eggbot-atc convert 그림.svg -o 출력.gcode
```

UGS에서 영점 잡고 `출력.gcode` 열어서 ▶. 첫 실행은 **펜 없이, `atc_feed`를 낮춰서** ATC 동작만 눈으로 확인하세요.
