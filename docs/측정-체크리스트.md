# 측정 체크리스트

조립이 끝난 기계에서 직접 재서 `machine.toml`에 넣어야 하는 값입니다. **위에서부터 순서대로** 재세요 (앞 값이 있어야 뒤 값을 잴 수 있습니다).
각 값의 자세한 설명은 [설정값-목록.md](설정값-목록.md)에 있습니다.

## 0. 재기 전에

- [ ] 펌웨어: [`firmware/grbl-mega-5x-d6.hex`](../firmware/README.md)를 Mega에 올림 (`SPINDLE_PWM_ON_D6`으로 빌드된 것)
- [ ] `uv run eggbot-atc settings` 출력을 UGS 콘솔에 붙여넣음
- [ ] UGS에서 `$3`(방향)을 맞춤: 각 축 `+10` 조그 시 원하는 방향으로 도는지
- [ ] 영점 잡기 (README "영점 잡기"): X 왼쪽 끝, A 완전 후퇴, 매거진 슬롯 1이 팔과 마주 봄 → `G92 X0 Y0 Z0 A0`

## 1. 확인만 하면 되는 값 (기본값 있음)

틀리면 고칩니다. 맞으면 그대로 둡니다.

| 순서 | 키 | 지금 값 | 어떻게 확인 | 잰 값 |
|---|---|---|---|---|
| 1 | `machine.microsteps` | `32` | DRV8825 점퍼 3개 다 꽂혔는지 눈으로 | |
| 2 | `machine.a_lead_mm` | `8` | `G91 G1 A10 F200` 후 슬라이드가 10 mm 갔는지 자로. 2.5 mm만 가면 리드 2 → `2` | |
| 3 | `drawing.pen_up_cmd` | `"M3 S90"` | UGS에서 `M3 S` 값을 바꿔 가며 펜이 계란에서 확실히 뜨는 값 | |
| 4 | `drawing.pen_down_cmd` | `"M3 S30"` | 펜이 계란에 살짝 닿는 값 | |
| 5 | `atc.twist_deg` | `45` | 펜을 문 갈퀴에서 Z만 돌려, 갈퀴가 펜에서 완전히 비켜나는 각도 | |

## 2. 꼭 재야 하는 값 (안 채우면 변환 거부)

| 순서 | 키 | 단위 | 무엇 | 어떻게 재나 | 잰 값 |
|---|---|---|---|---|---|
| 6 | `machine.x_max_deg` | 도 | 펜 암이 돌 수 있는 최대 각도 | 영점(왼쪽 끝)에서 오른쪽 끝까지 X 조그, 화면의 X 값 | |
| 7 | `drawing.x_offset_deg` | 도 | 그림 왼쪽 끝이 놓일 X | 펜이 계란 그림 영역 왼쪽 끝에 닿는 X | |
| 8 | `drawing.svg_width_deg` | 도 | 그림 가로 전체에 해당하는 펜 암 회전각 | 그림 영역 오른쪽 끝 X − 7번 값. `7번 + 8번 ≤ 6번` | |
| 9 | `atc.slot0_deg` | 도 | 슬롯 1의 매거진(Z) 각도 | 영점을 슬롯 1에 맞췄으면 `0` | |
| 10 | `atc.slide_out_mm` | mm | 슬라이드 완전 후퇴 (그리는 동안) | 영점에서 잡았으면 `0` | |
| 11 | `atc.park_x` | 도 | 펜 암이 매거진 갈퀴와 만나는 X | 펜을 단 채로 X를 돌려, 슬라이드를 밀면 펜 고정부가 갈퀴 안에 들어오는 X | |
| 12 | `atc.slide_in_mm` | mm | 매거진이 팔에 밀착된 A | X를 11번 값에 두고 A를 천천히 밀어 펜 고정부가 팔 자석에 닿는 A | |
| 13 | `atc.release_x` | 도 | 펜을 갈퀴에 두고 팔만 빠진 X | 갈퀴가 펜을 감싼 상태에서 X를 돌려 자석이 완전히 떨어지는 X | |

## 3. 다 쟀으면

1. `machine.toml`에 값을 적거나, GitHub 이슈 "측정값 전달"로 올립니다.
2. `uv run eggbot-atc check` → `all measured`가 나오면 끝.
3. 첫 시운전은 **펜 없이**, `atc_feed = 200`으로 낮춰서 펜 교체 동작만 봅니다.
