# 기구 치수

팀 도면(2026-10-02 기준)에서 소프트웨어 설정과 조립에 필요한 수치만 옮겼습니다. 단위는 mm입니다.
프레임·ATC는 STEP 모델과 대조했습니다. 펜 암과 전체 조립(`total.stp`)은 2026-10-09에 받은 STEP과 대조했습니다.
도면 원본(PDF·CATIA·PPT)은 저장소에 올리지 않습니다. 도면이 바뀌면 이 표도 같이 고칩니다.

## 1. 설정값에 쓰인 근거

| 설정 | 값 | 도면 근거 |
|---|---|---|
| X축 단위 | 도(°) | 펜 암 하단이 모터 축에 직결(Ø5.2 구멍 + M4 고정나사). 리드스크루 없음 |
| `machine.x_gear_ratio` | 1 | 위와 같음 |
| `machine.y_gear_ratio` | 1 | 클램핑 컵이 모터 축에 직결(Ø5.25) |
| `machine.z_gear_ratio` | 1 | 매거진 허브가 모터 축에 직결(Ø5.2 + Ø3.3 고정나사) |
| `machine.a_lead_mm` | 8 (확인 필요) | Sliding Mount Module에 T8 너트 자리(Ø10.2). 4줄이면 8, 1줄이면 2 |
| `atc.slot_count` | 3 | 매거진 포크 3개, 120° 간격 |

## 4. 펜 암

| 부품 | 외형 | 주요 치수 |
|---|---|---|
| 펜 암 하단 | 62.5 × 20 × 14 (STEP은 탭 포함 폭 18) | 모터 축 Ø5.2 + M4 고정나사 (너트 홈 10 × 8 × 2.5), 힌지 2-Ø5 (러그 폭 5), 모서리 2×45° 3곳 + 1×45° 1곳 (STEP), 탭 구멍 2-Ø4.13 깊이 7 (간격 26.5, STEP에만 있음) |
| 펜 암 상단 | 40 × 28 × 15 (STEP은 소켓 테두리 포함 43 × 31) | 힌지 Ø5, 자석 자리 2-Ø6 깊이 2, 핀 구멍 2-Ø2.2 H7 깊이 3 (STEP에는 없음), 끝단 R3, Ø1.5 구멍, 깊이 3 소켓 (STEP) |
| 펜 고정부 | 30 × 20 × 7 (핀 포함 33) | 펜 구멍 Ø10 (도면 표기는 Ø 없이 '10'), 펜 고정 M4 관통, 자석 자리 2-Ø6 깊이 2 (STEP은 옆면에 1개 더, 총 3), 핀 2-Ø2 f6 (돌출 3, STEP에는 없음) |

도킹: 펜 고정부와 펜 암 상단이 Ø6×2 자석 2쌍으로 붙고, Ø2 핀 2개가 위치를 맞춥니다. 테이퍼 핀이 아니라 직선 핀입니다. STEP(2026-10-09)에는 핀이 없고, 대신 펜 고정부 끝 3 mm가 펜 암 상단의 깊이 3 소켓에 끼워지는 형태입니다 (겹침 0으로 맞음). **STEP 방식(핀 없이 홈 + 자석)으로 만들기로 함 (2026-10-09).**

## 5. 전체 조립 (`total.stp`, 2026-10-09)

| 항목 | 값 |
|---|---|
| 펜 암 회전축(X) ↔ 계란 축(Y) | 한 점에서 만남. 펜 구멍 축도 같은 점을 지남 → 펜 끝은 계란 중심을 향함 |
| 매거진 축 ↔ 펜 구멍 축 | 63.5 (매거진 포크 반경 63.5와 같음). 단, 슬라이드가 한 위치에 있을 때 값 |
| 펜 암 회전축 → 힌지 | 48.5 |
| 힌지 → 펜 구멍 축 | 56.0 |
| 두 계란 컵 끝면 사이 | 60.0 |

`total.stp`에 계란·펜이 없어서 계란 길이 맞춤과 펜 끝 위치는 STEP으로 알 수 없습니다. 위 값들은 `x_max_deg`·`park_x` 등을 잴 때 참고용이고, 실제 값은 여전히 기계에서 잽니다.

## 6. 도면 확인 필요

| 항목 | 내용 |
|---|---|
| 모터 고정대 4-Ø2.46 | NEMA17 볼트(M3)가 고정대를 통과해 모터 탭에 체결되므로 통과 구멍 Ø3.2~3.4가 필요합니다. ATC 쪽 모터 마운트는 Ø3.2로 되어 있습니다. |
| 매거진 모터 자리 | Sliding Mount Module의 모터 구멍이 도면 Ø22.5, STEP Ø22.02로 다릅니다. Ø22.02는 NEMA17 보스(Ø22)에 거의 꽉 낍니다. 볼트 구멍도 STEP에서 31.2 × 31.5로 정사각형이 아니라서, NEMA17(31 × 31)에 M3(Ø3.2 구멍)가 한쪽에서 어긋날 수 있습니다. |
| 핀 Ø2 f6 ↔ 구멍 Ø2.2 H7 | 끼워맞춤은 기준 치수가 같아야 성립합니다. 둘 다 Ø2(H7/f6 헐거운 끼워맞춤)로 맞추고, 0.2가 3D 출력 보정값이면 그렇게 적어 둡니다. |
| 샤프트 Ø8.3 ↔ LM8LUU | 구매한 LM8LUU(외경 15)가 Sliding Mount Module의 Ø8.3 구멍에 맞지 않습니다. |
| 프레임 체결 구멍 | 베이스 프레임과 받침대가 둘 다 Ø2.46이면 볼트가 지나가는 쪽은 통과 구멍이어야 합니다. 조립 방향을 확인해야 합니다. |
| 계란 축 높이 4 mm 차이 | `total.stp`에서 모터 쪽(클램핑 컵) 축은 높이 46.2, 반대쪽(센터링 컵) 축은 50.2입니다. 계란이 4 mm 기울어집니다. 반대쪽 고정부(`계란 컵쪽 고정부`)는 볼트 구멍 중심도 Ø22 축보다 1.0 mm 어긋나 있습니다. |
| 다섯 번째 모터 | ✅ 실제 구동하는 모터로 확인됨. RAMPS E1 소켓, 펌웨어에서 Y 복제 ([배선도](배선도.md) 3장). 모터·드라이버 1개씩 추가 구매 |
| 센터링 컵 뒤쪽 | 도면은 뒤쪽 포켓 Ø22.25 × 7, STEP은 Ø8 구멍(깊이 15) + Ø12 × 3 카운터보어입니다. 다섯 번째 모터 축을 받는 형태로 바뀐 것으로 보입니다. |
| 펜 도킹 핀 | ✅ STEP 방식(3 mm 홈 + 자석)으로 결정. 펜 고정부 옆면의 세 번째 자석 자리 용도는 아직 확인 필요. |
| 클램핑 컵 옆 구멍 | STEP에 축과 직각인 Ø5.25 구멍이 있습니다. 고정나사 자리라면 M4 탭(Ø3.3)이어야 합니다. |
| 도킹 축 | ✅ 매거진(Z)을 45° 돌려 갈퀴로 거는 방식으로 결정 (2026-10-09, 팀원 프로그램 방식). README "ATC 펜 교체" 참고. |
