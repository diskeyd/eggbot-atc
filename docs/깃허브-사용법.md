# GitHub가 처음인 분을 위한 안내

이 저장소는 웹 브라우저만으로 쓸 수 있습니다. 명령어는 하나도 필요 없습니다.

## 단어 3개

- **저장소(Repository)** : 코드가 들어 있는 폴더 페이지. 주소는 `https://github.com/diskeyd/eggbot-atc`
- **이슈(Issue)** : "이거 고쳐 주세요 / 값 잰 거 여기 있어요" 하는 게시글. 수정 요청은 전부 이걸로 합니다.
- **커밋(Commit)** : 저장 기록. 코드가 고쳐지면 커밋이 하나 늘어납니다. 직접 만들 일은 없습니다.

## 1. 계정 만들기 (한 번만)

1. https://github.com 접속 → 오른쪽 위 **Sign up**
2. 이메일, 비밀번호, 아이디(username) 입력 → 이메일로 온 인증 코드 입력
3. 만든 **아이디**를 저에게 알려 주세요. (비밀번호는 알려 주지 마세요)

## 2. 코드 보기·받기

1. `https://github.com/diskeyd/eggbot-atc` 접속
2. 초록색 **`<> Code`** 버튼 → 맨 아래 **Download ZIP**
3. 압축을 풀고, 그 폴더의 `README.md`에 있는 순서대로 실행
4. 나중에 익숙해지면 `git clone` 이라는 방법도 있지만 지금은 ZIP이면 충분합니다.

## 3. 수정 요청하기 (이슈 올리기)

1. 저장소 페이지 위쪽 탭에서 **Issues** 클릭
2. 초록색 **New issue** 클릭
3. 양식 3개 중 하나 선택 → **Get started**
   - **측정값 전달** : 기계에서 잰 숫자를 알려줄 때
   - **버그 신고** : 실행했는데 오류가 나거나 이상하게 동작할 때
   - **기능 요청** : "이런 것도 되게 해 주세요"
4. 빈칸을 채웁니다. 양식에 적힌 예시처럼 쓰면 됩니다.
5. 오른쪽 아래 **Submit new issue** 클릭. 끝.

### 잘 쓴 예

**측정값 전달**
> 키: `atc.park_x`
> 값: `72.5`
> 어떻게 쟀나: UGS 조그로 X를 옮겨서 슬라이드가 들어와도 안 부딪히는 자리. 화면의 X 좌표를 읽음.

**버그 신고**
> 실행한 명령: `uv run eggbot-atc convert 계란도안.svg -o out.gcode`
> 나온 메시지: (터미널에 나온 내용을 전부 복사해서 붙여넣기)
> 기대한 것: out.gcode 파일이 생겨야 함
> 첨부: 계란도안.svg (파일을 글쓰기 칸에 끌어다 놓으면 첨부됩니다)

## 4. 답변 보기·대화하기

- 올린 이슈는 **Issues** 탭에 목록으로 보입니다. 클릭하면 아래에 댓글이 달립니다.
- 제가 코드를 고치면 이슈에 "완료" 댓글을 달고 이슈를 **닫습니다(Closed)**. 닫힌 이슈는 목록에서 **Closed**를 눌러야 보입니다.
- 가입한 이메일로도 알림이 옵니다.
- 추가로 할 말이 있으면 같은 이슈 아래 댓글 칸에 쓰고 **Comment**.

## 5. 고쳐진 코드 다시 받기

2번을 다시 하면 됩니다 (ZIP 새로 받기).
단, **본인이 값을 채운 `machine.toml`은 덮어쓰지 말고 그대로 두세요.** 새 ZIP의 `machine.toml`은 빈 템플릿입니다.

## 6. 조심할 것

이 저장소는 **공개**입니다. 누구나 볼 수 있습니다.
- 이슈에 전화번호, 학번, 주소 같은 개인정보를 쓰지 마세요.
- 사진을 올릴 때 얼굴이나 이름표가 찍혔는지 확인하세요.

## 자주 막히는 것

| 상황 | 해결 |
|---|---|
| 로그인이 안 됨 | 로그인 화면의 **Forgot password?** 로 재설정. 아이디가 아니라 이메일로 로그인해도 됩니다 |
| Issues 탭이 안 보임 | 저장소 주소를 다시 확인 (`diskeyd/eggbot-atc`). 화면이 좁으면 탭이 `···` 메뉴 안에 숨습니다 |
| 오류 메시지를 어떻게 복사하나 | 터미널에서 마우스로 드래그 → `⌘C`(Mac) / `Ctrl+C`(Windows). 전체가 길어도 다 붙여넣는 게 좋습니다 |
| 파일(그림, 사진)을 첨부하고 싶다 | 이슈 글쓰기 칸에 파일을 **끌어다 놓기**. 자동으로 링크가 생깁니다 |
| 어떤 양식을 골라야 할지 모르겠다 | **버그 신고**로 올리세요. 제가 분류합니다 |
