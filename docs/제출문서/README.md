## 다시 만들기

macOS에서 Chrome과 poppler(`pdfinfo`, `pdftotext`)가 있어야 합니다. 글꼴(Pretendard, SIL OFL 1.1)은 처음 한 번 내려받습니다.

```bash
python3 docs/제출문서/build.py
```

본문을 고치면 `report.html`을 수정하고 위 명령을 다시 실행합니다. 목차 쪽번호는 두 번 렌더링해서 자동으로 채웁니다. PDF는 매번 바이너리가 바뀌므로, 내용이 바뀐 때만 다시 커밋하세요.

## 이 문서가 확인하지 않은 것

- 프로그램 실행, EXE 빌드, Windows 동작, 기계 연결은 확인하지 않았습니다. 소스 읽기와 구문 검사(Python AST 파싱)만 했습니다.
- 설정값은 설정 화면과 소스 초기값입니다. 기계 실측으로 안전성을 확인한 값이 아닙니다.
