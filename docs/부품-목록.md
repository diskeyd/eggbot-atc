## 3. 더 사야 하는 것 — 이유

- **Ø8 샤프트 300 mm 2개**: 이전 목록에는 있었는데 이번 리스트에 없습니다.
- **T8 리드스크루**: 3D 모델은 "8 mm × 2 mm 피치"입니다. 리드가 2인지 8인지 판매 페이지에서 확인해 `a_lead_mm`에 넣습니다.
- **자석 8개**: 펜 고정부 3개 × 2 + 펜 암 상단 2. 3D 모델의 펜 고정부 옆면 자석 자리는 용도 확인 전이라 수량에 넣지 않았습니다. 핀은 3D 모델 방식(3 mm 홈 + 자석)이라 필요 없습니다.
- **M4 무두볼트 5개**: 펜 암 하단 1, 펜 고정 3, 매거진 허브 1.

## 4. 조립할 때 주의

- **배선**은 [배선도.md](배선도.md) 순서대로. 특히 전원 단자 5A 쌍, 서보 신호 D6, DC-DC 5.0 V 확인.
- **Mega 2560**: 호환품도 grbl-Mega-5X는 똑같이 동작합니다. 호환품은 PC에 CH340 드라이버 설치가 필요할 수 있습니다.
