## 2. 구매 리스트 확인

| NO | 품목 | 확인 결과 |

| 3 | 드라이버 | TMC2209가 아니라 **DRV8825**입니다. 마이크로스텝 점퍼 3개 모두 = 1/32 ([배선도](배선도.md) 4장) |
| 5 | 스텝모터 | 모터 4개 + 케이블 4개입니다. 3D 모델에는 모터가 **5개**(계란 양쪽)라서 1개가 모자랍니다 |
| 7 | 어댑터 | 12 V 10 A면 모터 5개 + 서보에 충분합니다 |

## 3. 더 사야 하는 것

| 축 / 기능 | 부품 | 비고 |
|---|---|---|
| 계란 반대쪽 모터 | **NEMA17 + 케이블 1개, DRV8825 1개** | RAMPS E1 소켓. 같은 모델(CIG 4240)로 맞춤 |
| X (펜 암 회전) | M4 무두볼트 1, 힌지 핀 Ø5 (길이 20 이상) 1 | 펜 암 하단이 모터 축에 직결(Ø5.2 + M4). 펜 암 상단은 Ø5 핀으로 하단에 연결 |
| A (슬라이드) | Ø8 샤프트 300 mm 2개, T8 리드스크루 + 플랜지 너트, 커플러 5→8 mm | 이전 목록에 있던 샤프트가 이번 리스트에 없습니다. 3D 모델의 리드스크루는 "8 mm × 2 mm 피치"라 리드가 2인지 8인지 판매 페이지에서 확인 후 `a_lead_mm`에 반영 |
| Y (계란 회전) | 클램핑 컵 고정나사 1 | 클램핑 컵·센터링 컵·모터 고정대는 3D 출력품 |
| ATC | 네오디뮴 자석 Ø6×2 mm 8개, M4 무두볼트 4개 | 자석: 펜 고정부 3개 × 2 + 펜 암 상단 2. 3D 모델의 펜 고정부 옆면 자석 자리는 용도 확인 전이라 수량에 넣지 않음. 핀은 필요 없음(3D 모델 방식: 3 mm 홈 + 자석). M4: 펜 고정 3 + 매거진 허브 1 |
| 선택 | 엔드스탑 | 달면 `home_cmd = "$H"`로 자동 원점복귀 |
| 선택 | 여분 DRV8825 1개 | 드라이버는 거꾸로 꽂거나 정전기로 잘 죽음 |

## 4. 조립할 때 주의

- **배선**은 [배선도.md](배선도.md) 순서대로. 특히 전원 단자 5A 쌍, 서보 신호 D6, DC-DC 5.0 V 확인.
- **Mega 2560**: 호환품도 grbl-Mega-5X는 똑같이 동작합니다. 호환품은 PC에 CH340 드라이버 설치가 필요할 수 있습니다.
